## Engineering

I focus on building services that are easy to understand, test and operate in production.

```text
API
 ├── HTTP / gRPC
 │
Application
 ├── use cases
 ├── business logic
 │
Domain
 ├── entities
 ├── interfaces
 │
Infrastructure
 ├── PostgreSQL
 ├── Redis
 ├── Kafka
 └── external services
```

Some of the things I pay attention to:

* clear package boundaries
* small and explicit interfaces
* context propagation
* graceful shutdown
* timeouts and cancellation
* idempotency
* retries and backoff
* database transactions
* connection pooling
* structured logging
* metrics and distributed tracing
* race conditions and concurrent workloads
* profiling and performance benchmarks
